# 数字文件整理小指南

把资料放在找得到的地方，比一口气整理所有文件更重要。

## 1. 建立简单的目录

- 收件箱：临时保存刚收到、还没分类的资料。
- 工作：按项目或主题建立文件夹。
- 生活：保存照片、旅行计划和日常记录。
- 归档：保存已经完成、但暂时不能删除的内容。

## 2. 让文件名说清楚内容

建议使用「日期_主题_版本」的结构。
例如：2026-10-30_旅行清单_v1.txt。
避免反复使用「最终版」「最终最终版」等名称。

## 3. 每周花十分钟维护

1. 清空收件箱，把资料移动到对应目录。
2. 检查下载文件夹，删除确认不再需要的重复副本。
3. 把完成的项目移入归档。
4. 确认重要资料已有备份。

## 4. 给重要资料留一个备份

工作电脑上的文件、移动硬盘副本与可靠云存储可以相互补充。
先确认备份能够打开，再处理旧文件。
私人证件、密码和敏感资料不适合放进公开分享目录。
