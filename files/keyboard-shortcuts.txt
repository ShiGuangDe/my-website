Windows 日常效率快捷键
=====================

窗口与桌面
Win + E              打开文件资源管理器
Win + D              显示或返回桌面
Alt + Tab            在已打开的窗口之间切换
Win + 左/右方向键     将当前窗口贴靠到一侧
Win + L              锁定电脑

文件操作
Ctrl + C             复制选中内容
Ctrl + X             剪切选中内容
Ctrl + V             粘贴
Ctrl + Z             撤销上一步操作（取决于当前应用）
F2                   重命名选中的文件
Ctrl + Shift + N     在文件资源管理器中新建文件夹
Alt + Enter          查看选中文件的属性

浏览器操作
Ctrl + L             选中地址栏
Ctrl + T             新建标签页
Ctrl + W             关闭当前标签页
Ctrl + Shift + T     重新打开最近关闭的标签页
Ctrl + F             在当前页面中查找
Ctrl + 加号/减号      放大或缩小页面
Ctrl + 0             恢复默认页面缩放

提示：快捷键可能因应用和系统设置而有所不同。
